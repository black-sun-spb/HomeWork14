# Проект Категорий и Товаров

В этом проекте реализована комплексная система для управления товарами и категориями с поддержкой расширенной функциональности и удобным интерфейсом.

# Основные классы и функциональность

# Базовые классы

• BaseProduct — абстрактный базовый класс, который задаёт общие требования к товарам.

• Product — класс товара с атрибутами:

    • name — название товара

    • description — описание товара

    • price — цена (приватный атрибут с геттером и сеттером с валидацией)

    • quantity — количество на складе

Наследники Product:

• Smartphone — смартфон с дополнительными атрибутами:

    • efficiency — производительность

    • model — модель

    • memory — объем встроенной памяти

    • color — цвет

• LawnGrass — трава газонная с дополнительными атрибутами:

    • country — страна-производитель

    • germination_period — срок прорастания

    • color — цвет

# Миксин

CreationLoggerMixin — миксин, который при создании любого продукта печатает в консоль информацию о создаваемом объекте (класс и параметры).

# Категории

• Category — класс категории с атрибутами:

    • name — название категории

    • description — описание категории

    • приватный список товаров категории

В категории реализована строгая проверка — в список можно добавлять только объекты класса Product или его наследников.

Поддерживается строковое отображение категории с подсчетом общего количества товаров.

Для удобства реализован итератор по товарам категории (поддержка цикла for).

Подсчитываются общее количество созданных категорий и товаров через атрибуты класса.

# Дополнительный класс
• Order — класс для описания заказа с атрибутами:

    • ссылка на купленный товар (Product)

    • количество купленного товара

    • итоговая стоимость заказа (рассчитывается автоматически)

# Особенности и дополнительные возможности
Перегружен оператор сложения + для товаров, который возвращает суммарную стоимость по количеству и цене.

Сложение товаров разных классов запрещено и вызывает исключение TypeError.

При установке цены реализована валидация и подтверждение снижения цены через ввод пользователя.

Загрузка категорий и товаров из JSON-файла (loader.py) с удобной структурой данных.

## Пример использования

```python
from src.loader import load_categories_from_json

categories = load_categories_from_json("products.json")

for category in categories:
    print(f"Категория: {category.name}, товаров: {len(category.products)}")
    for product in category:
        print(f"  {product}")

# Создание заказа
from src.order import Order

order = Order(product=categories[0].products[0], quantity=3)
print(f"Итоговая стоимость заказа: {order.total_price} руб.")
```
