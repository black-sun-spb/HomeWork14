# Проект Категорий и Товаров

В этом проекте реализованы основные классы для работы с товарами и категориями:

- Класс `Product` описывает товар с такими атрибутами, как:
  - название (`name`)
  - описание (`description`)
  - цена (`price`)
  - количество на складе (`quantity`)

- Класс `Category` описывает категорию товаров с атрибутами:
  - название (`name`)
  - описание (`description`)
  - список товаров категории (`products`)

Для класса `Category` реализованы также два атрибута класса, которые автоматически отслеживают общее количество созданных категорий и товаров.

Дополнительно реализована функция загрузки данных из JSON-файла (`products.json`), которая позволяет создавать объекты `Category` и `Product` на основе данных из файла.

## Тестирование

Написаны юнит-тесты для классов Product и Category, которые проверяют:

Правильный подсчет общего количества созданных категорий.

Для тестирования используется pytest.
